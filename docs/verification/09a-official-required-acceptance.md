# 공식 필수 기능 인수 기록

상태: 로컬 준비 중. `requirements/01-contest-requirements.md`와 `requirements/02-acceptance-tests.md`의 필수 항목을 최종 제품에서 다시 확인한다. 합성 브라우저·로컬 HTTPS 결과와 실제 물리 기기·외부망 결과를 같은 증거로 합치지 않는다.

## 로컬 최종 제품 검사

| 범위 | 공개 경계에서 확인할 결과 | 현재 |
| --- | --- | --- |
| 인증 | 가입→로그인→새로고침 복구→로그아웃; 비로그인 보호 API 거절 | 기존 01/04 회귀 근거가 있으며 최종 제품 재실행 대기 |
| 평가 로그인 | 기본 비활성, 부분 설정 시작 실패, 활성 버튼→정상 서버 세션, Origin·IP/계정 제한, 로그아웃 | 미구현 |
| 방송 관리 | 등록→목록/상세→수정→삭제, 서버 재시작 뒤 영속 조회, 활성 중 삭제 거절 | 기존 01/04 근거가 있으며 최종 제품 재실행 대기 |
| 권한 | 소유자 허용, 다른 로그인 사용자·비로그인 수정/삭제/송출 제어 거절; 익명 목록·시청 허용 | 기존 01/04-B 근거가 있으며 최종 제품 재실행 대기 |
| PC 송출 | 화면 변화, 공유 소리+마이크를 구분해 수신, 시작/공유중지/종료와 FFmpeg·ingress 부재 | 로컬 두 Chrome 합성 흐름 통과; 실제 PC 장치 확인 대기 |
| 모바일 송출 | 카메라 H264+마이크 Opus, 시작/종료, 다른 기기 익명 시청 | 로컬 합성 카메라 흐름 통과; 실제 iPhone 확인 대기 |
| 종료·장애 | known/unknown 작업 완료 근거 저장 후 ENDED; 중간 장애에서 STOPPING 유지 및 재시도 | 07-A2 정상·자연 종료·저장 실패 재시도 통과; 전체 제품 barrier/epoch 매트릭스 대기 |

각 검사에는 제품 commit, 전용 스택 이미지 digest, 실행 명령·종료 코드, API 응답·DB 상태, 미디어 자원 신원과 관측 기기/브라우저를 기록한다. 비밀·SDP·개인 IP는 기록하지 않는다. 모든 테스트는 기존 서비스와 다른 전용 네임스페이스·포트·볼륨에서 실행하고 기존 helper8090을 보존한다.

## 공개 서비스와 물리 기기

| 필수 확인 | 관측 방법 | 상태 |
| --- | --- | --- |
| `https://live.wombatburrow.com` 실제 접속 | 다른 회선의 브라우저에서 신뢰 TLS와 UI/API 응답 | 미완료: 현재 미배포 |
| 평가 로그인 | 심사자가 README 절차대로 버튼을 눌러 로그인·방송 등록·로그아웃 | 미완료 |
| PC→다른 기기 시청 | 실제 PC 화면 공유와 탭 소리·마이크를 별도 기기에서 영상·두 음원으로 구분 | 미완료 |
| iPhone Chrome→다른 기기 시청 | 실제 카메라·마이크 권한, 송출·재생·중지·종료와 이전 HLS 차단 | 미완료 |
| 외부망 송출/시청 | 모바일 회선에서 WHIP ICE와 HLS 데이터 흐름, 단순 HTTP 연결 이외의 미디어 수신 | 미완료 |
| 지속성·권한 | 배포 DB/API 재시작 뒤 방송 정보, 타 사용자·비로그인 서버 거절 | 미완료 |

공개 DNS·Caddy·ICE 포트는 기존 서비스에 영향을 주지 않도록 별도 배포 검토와 복귀 경로를 먼저 마련한다. 실제 Labtop 접근과 iPhone·외부 회선이 가능한 시점에만 위 미완료 칸을 관측 결과로 바꾼다. README 서비스 URL·평가 로그인·지원 환경은 관측 뒤 최종 값으로 갱신한다.
