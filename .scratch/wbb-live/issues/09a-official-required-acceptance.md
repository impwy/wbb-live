# 09-A: 공식 필수 기능의 공개 인수

**Status:** needs-info
**Blocked by:** 07-A2 제품 종료 완료 통합. 실제 iPhone과 Labtop 외부 접속 환경은 별도 인수 관문이다.
**목표:** 공모 필수 항목을 공개 HTTPS 서비스와 두 물리 기기에서 재현하고 README만으로 평가자가 같은 절차를 실행하게 한다.

## 구현 범위

1. 현재 검증된 단일 품질 PC 화면·공유 소리+마이크, 휴대폰 카메라+마이크, 익명 목록·상세·시청, 이메일 인증·방송 CRUD·소유자 권한 및 정확한 종료를 공개 서비스에 연결한다. ABR·댓글·도네이션·녹화와 대규모 부하는 이 필수 인수의 완료 조건이 아니다.
2. WBB 전용 k3s namespace·데이터 볼륨·비밀 주입, Caddy `live.wombatburrow.com` HTTPS, 브라우저가 접근할 WHIP ICE UDP/TCP 경로를 구성한다. 기존 서비스·데이터는 유지하고 DB·Redis·Kafka·MediaMTX 관리 API를 외부에 열지 않는다. 외부 변경은 실제 접근 가능성과 사용자 지시를 확인한 뒤 실행한다.
3. 평가 계정은 운영 환경에서 별도로 안전하게 만들고 권한을 확인한다. 실제 비밀번호·토큰은 Git·문서·로그에 넣지 않는다. README에는 서비스 URL, 평가 로그인 방식, 환경변수 자리표시자, clean checkout 실행, PC/모바일 송출·시청·종료 절차, 확인된 브라우저·기기와 한계를 기록한다.
4. 외부 접속 전에 로컬 전용 환경에서 최종 제품의 가입·로그인·로그아웃, CRUD, 비로그인 조회·시청, 소유자/타 사용자/비로그인 권한, PC 두 음원, 모바일 카메라·마이크, 종료·재시작 영속성을 공개 HTTP 및 Flutter UI로 검증한다.

## 인수 기준

- 실제 PC Chrome/Edge의 탭 공유 소리와 마이크를 별도 물리 기기에서 구분해 듣고 화면 변화를 본다. 방송 시작·공유 중지·종료 뒤 기존 미디어 연결/URL이 종료되는지 확인한다.
- 실제 iPhone Chrome에서 카메라·마이크를 송출하고 다른 물리 기기에서 영상·음성을 본다. 시작·종료 및 권한 거절을 확인한다. 모바일 화면 잠금·백그라운드 지속은 지원으로 추정하지 않는다.
- 모바일 회선 등 외부망에서 공개 HTTPS URL에 접속해 익명 시청과 평가 로그인을 수행한다. 브라우저 신호 연결뿐 아니라 실제 RTP 수신·HLS 재생을 확인한다.
- API/DB 재시작 후 방송 제목·설명·종료 상태를 다시 조회한다. 보호 API의 비로그인·타 사용자 거절과 소유자 허용을 서버 응답으로 확인한다.
- 공개 저장소 clean checkout의 빌드·테스트·실행 절차를 재현하고 비밀·개인 로컬 경로·잘못된 서비스 주소가 게시물에 없는지 검사한다.

실제 기기나 외부 접속이 불가능한 동안은 로컬 구현·자동 검사만 기록하고 공식 인수를 통과로 표시하지 않는다. 프로젝트의 03 ABR, 07-B Kafka inbox, 08 관측성 및 09 운영 규모 목표는 별도 티켓으로 계속 추적한다.
