# 01 프런트엔드 흐름 리뷰

작성: 2026-11-06. 범위: Flutter Web 인증·방송 CRUD. 독립 Codex 리뷰 에이전트와 root가 검토하고 pi GLM이 수정했다. 라이브 송출·시청의 완료 검증은 아니다.

## 발견과 처리

| 문제 | 처리 | 검증 |
| --- | --- | --- |
| 연결·JSON 오류가 무한 로딩으로 남음 | API 오류 정규화, 로딩 종료, 재시도 UI | ClientException 뒤 오류 표시·재시도 성공 테스트 |
| 최종 refresh401 후 로그인 표시 유지 | 세션 만료 이벤트와 재로그인 안내 | 보호 요청401→refresh401→비로그인 상태 테스트 |
| logout 실패 시 토큰과 UI 상태 불일치 | 실패 시 상태 유지·오류 안내·재시도 | logout503 후 로그인 상태 유지 테스트 |
| 수정409 후 최신 버전 재조회 불가 | 최신 데이터 불러오기와 version 갱신 | version1 충돌→version5 조회→수정 성공 테스트 |

독립 재리뷰에서 위 네 기능 수정은 종결 가능으로 판단했다. single-flight는 같은 ApiClient 인스턴스에만 적용된다. 실제 두 브라우저 탭의 동시 refresh 검증은 아직 수행하지 않았으며 탭 간 동기화를 보장하지 않는다. 이 경우 세션 만료와 재로그인 안내로 처리하는 계약이다.

## Codex 실행 근거

- `flutter analyze`: 통과.
- `flutter test`: 15개 통과.
- `flutter build web --release --no-web-resources-cdn`: 통과.
- 실제 로컬 Chrome: 가입→로그인→내 방송 등록→수정→새로고침 후 로그인 복원→상세 조회→삭제→로그아웃을 수행했다.
- 로그아웃 후 쿠키가 제거됐으며 localStorage와 sessionStorage에 항목이 없었다.
- 데스크톱과390px 뷰포트 화면을 확인했다. 뷰포트 검사는 실제 휴대폰 브라우저·카메라·마이크 검증을 대체하지 않는다.

## 추가 발견과 최종 확인

- 내 방송에서 홈으로 돌아오면 목록이 갱신되지 않았다. 탐색 복귀 후 재조회하도록 수정됐으며 실제 브라우저에서 새 방송이 즉시 목록에 나타나는 것을 확인했다.
- 한글 fallback 폰트가 `fonts.gstatic.com`에서 내려왔다. Noto Sans KR과 OFL 라이선스를 번들했고, 새 브라우저 세션의 전체 리소스 요청이 localhost로만 향하는 것을 확인했다.
- 내부 version·원시 상태값은 한국어 상태·수정일로 바뀌었고 방송 등록 버튼의 접근성 이름도 확인했다.

추가 수정 후 analyze·15개 테스트·release build를 다시 통과했다. 일부 번들 폰트에 없는 글리프는 지원하지 않을 수 있으며 README에 명시했다. 로컬 브라우저 증거와 실제 기기 미디어 검증을 구분한다.
