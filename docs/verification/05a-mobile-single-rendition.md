# 05-A 카메라·마이크 송출 검증

상태: 로컬 제품 구현·독립 검증 완료. 실제 iPhone·외부망 인수는 미완료다.

## 조정자 독립 검사

- Flutter analyze: 문제0건.
- Flutter 전체58개 통과 후 추가된 송출 실패 검사를 포함한 publisher8개 재실행 통과. 최초 검사 이후 변경된 Dart 파일은 해당 테스트뿐이었다. 구현자 최종 전체 검사 수는59개다.
- 최종 JS 대역7개 통과: 늦은 화면/마이크 권한, 공유 중지, 카메라 부분 캡처·늦은 권한·권한/장치 오류·H264 미지원, 숨김/pagehide, native HLS 대역. 실제 Safari 검사가 아니다.
- `flutter build web --release --no-web-resources-cdn`: 통과. 기존 CupertinoIcons 폰트 경고가 있으며 실제 아이콘 표시 확인을 대신하지 않는다.
- 독립 Chrome 정상 카메라 및 합성 숨김 종료: 모두 통과. 인계 시 저장한 제품/검증기 SHA-256과 두 실행 후 값이 동일했다.

## 실제 로컬 미디어 흐름

제품 Flutter UI에서 가입·로그인·방송 등록·카메라 시작을 수행하고 별도 Chrome 프로세스의 비로그인 사용자가 재생했다. 캡처는 합성 영상/660Hz 음성이며 모바일 viewport는 실제 휴대폰이 아니다. 실제 Go API·PostgreSQL·MediaMTX·FFmpeg·Caddy를 통과한다.

| 독립 실행 | 정상 중지 | 합성 숨김 종료 |
| --- | --- | --- |
| DB 송출 종류 | camera | camera |
| 송출·MediaMTX 트랙 | H264/Opus | H264/Opus |
| 익명 수신 decoded frames | 6 | 5 |
| 660Hz/배경 레벨 | 약-32.88/-90.05dB | 약-32.85/-89.05dB |
| 사용자 pause 유지 | 확인 | 확인 |
| 종료 후 playback/HLS | 409/403 | 409/403 |
| 사용한 publish grant 재사용 | 409 | 409 |
| 최종 회차 | 정확한 ended | 정확한 ended |
| 트랙·PeerConnection·FFmpeg·미디어 세션 정리 | 확인 | 확인 |
| 숨김 직후 로컬 트랙/PC 종료 | 해당 없음 | 확인 |
| 복귀 후 자동 재송출 | 미검증 | 없음 |

실제 worker 기록 exited, 기존 FFmpeg PID 부재, 회차의 ready path 및 WebRTC/RTSP 세션 부재도 검사했다. 종료 후 시청 UI의 재생 버튼이 비활성이다. 독립 검증 후 전용 DB ended32/활성0, 기존8090 HTTP200을 확인했다.

구현자 PC 화면 공유 회귀도 H264/Opus·익명12프레임·440/660Hz 두 음원·pause·종료/정리를 통과했다. 이는 조정자의 이번 카메라 독립 실행과 구분한다. 기존 PC 독립 근거는 [04-B2](04b2-flutter-live.md)를 따른다.

## 진단과 증거 한계

첫 카메라 실패는 fetch 관측 코드가 Dart HTTP의 바이트 본문을 JSON 문자열로 잘못 읽어 원요청을 막은 검증기 오류였다. 제품 captureOffer 단독 성공, HTTP 클라이언트 코드, 관측 수정 후 실제 UI 성공으로 확인했다. 실제 DB source도 별도로 검사한다.

숨김 검사의 최초 UI 대기는 숨겨진 화면의 렌더링을 기다려 실패했다. API로 서버 종료를 확인하고 화면 복귀 후 종료 표시를 검사하도록 순서를 수정했다. 합성 이벤트 성공은 실제 iPhone의 이벤트 전달을 증명하지 않는다. 복귀 시 서버 재조회는 위젯 검사로 확인한다.

사용된 grant의 재사용 거절은 관측했지만 종료 시점의 미사용 grant 폐기나 다른 사용자 권한 전체를 이 검사 하나로 증명하지 않는다. 기존04-B 서버 권한 검증과 함께 판단한다.

실제 iPhone Chrome 카메라·마이크, 물리 기기 간 영상/음성, 권한 창·잠금·앱 전환·회선 단절, 실제 외부망·Google 자격·VAAPI/ABR 인수는 미완료다. 합성 결과로 지원 환경이나 운영 용량을 보장하지 않는다.
