## 조정자 초기 검사

- Flutter30개 테스트 통과. Go 전체 `go test -race -count=1 ./...`와 `go vet ./...` 통과. 리뷰 수정 전 기준이며 수정 후 해당 회귀를 재검사한다.
- 실제 별도 API 실행 파일+전용 PostgreSQL/Redis에서17개 검사 통과: 가입/로그인/방송등록, 익명 시작 거절, 준비, 같은 키·같은 grant, 공개 응답 허용 필드만 노출, 활성 삭제 거절, 취소 요청/정리, 새 회차, 실제 API 프로세스와 DB 컨테이너 재시작 후 회차 보존·동일grant 재응답, Redis 중단 시 보호503·공개200, test clock 없이 실제60초 준비 제한 이후 종료, 영속 outbox의starting/stopping/ended3전이.

## 실행 중 조정한 검사 환경

첫 Go 실행은 기존 harness의 URL문자열 치환이postgres 사용자명까지 바꾸어 연결에 실패했다. 전용 DB 사용자명을 wbb로 맞춘 뒤 전체 검사가 통과했다. 첫 실제 재시작 검사는 Docker의 임의 host 포트가 재시작 후 바뀌어 연결에 실패했다. 실제 할당 포트를 재조회한 환경으로 반복해 통과했다. 두 실패를 제품 동작 통과로 기록하지 않는다.

## 리뷰 수정 검증 대기

요청 키 형식·지연 조회·다른 family 갱신/로그아웃 경합 3건의 수정 후 독립 재리뷰에서 원래 결함이 해결됐음을 확인했다. 구현자는 PostgreSQL 교착으로 logout 500을 실제 재현 후 수정했다. 이후 무효화된 조회가 미래 갱신을 막는 잔여 결함 1건의 수정·검사가 진행 중이다. 중간 독립 Flutter 전체 33개 검사는 통과했다.

- 수정 후 독립 Go 전체 race 검사와 vet 통과. PostgreSQL 경합 회귀를 포함한다.
