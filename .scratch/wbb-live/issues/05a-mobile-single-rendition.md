# 05-A: 단일 품질 모바일 카메라·마이크 송출

**Status:** in-review
**Blocked by:** 04-B1/04-B2 정상·권한·종료 미디어 인터페이스의 로컬 독립 검증 완료.03 ABR는 선행이 아니다. 부모04-B의 unknown POST 회수는07에 남기며 실제 기기 인수는 별도 유지한다.
**구현 담당:** 지정 pi 또는 사용자 승인 대체 Codex의 현재 단독 구현자.

## 목표

휴대폰에서 로그인한 방송 소유자가 카메라·마이크로 시작·종료하고 다른 기기의 비로그인 시청자가 영상·음성을 받는다. MOB-01~03, BCAST-02/03, AUTH-02/03의 필수 기능이다. 로컬 구현은 우선 진행하되 실제 모바일 인수 없이 전체 완료로 표시하지 않는다.

## 계약

- Flutter 상세의 모바일 송출을04의 API·grant·WHIP에 연결한다. source=camera, 영상과 음성 트랙 모두 확보, muted/playsinline 미리보기. 단일 품질은 실제 준비된 출력만 제공한다.
- 기존 카메라 실험의 캡처·자원 정리를 재사용하며 고정 실험 주소·무인증 송출 경로를 제품에 복사하지 않는다. Flutter Web 브리지는 시도별 캡처/송출/종료 상태와 오류를 전달한다. grant는 메모리에만 보관한다.
- 권한 거절, 장치 없음/사용 중, 부분 캡처, codec 불가, WHIP 실패, 시작 중 취소와 늦은 권한 응답을 처리한다. 모든 트랙과 PeerConnection을 정리하고 중복 회차를 생성하지 않는다.
- 종료·로그아웃·화면 이탈 시 로컬 캡처와 서버 송출 종료. 모바일 document 숨김을 관측하면 종료 요청하며 이벤트를 받지 못하면 서버 ingress 유실 제한으로 종료한다. 복귀 시 서버 상태를 조회하고 자동 재송출하지 않는다. 백그라운드/잠금 상태에서 계속 송출한다고 안내하지 않는다.
- 익명 시청은 재생 준비·방송 중·종료, 재생/소리 켜기·실패 재시도를 제공한다. 화면과 버튼을 모바일에서 조작할 수 있어야 한다. 카메라 전환은 별도 확장이다.

## 자동 검증

소유자/타인/익명, 권한·장치 실패, 시작 중 취소, 종료·로그아웃, 수명 이벤트와 늦은 응답을 Flutter 동작 경계에서 검사한다. 전용 실제 MediaMTX/FFmpeg와 독립 Chrome 프로세스에서 합성 카메라·음성→익명 수신 decoded frames/오디오→종료→이전 grant 거절을 확인한다. 이벤트 누락과 연결 단절에서도 서버 유실 감시/정리 재시도가 작동해야 한다. Go/Flutter 검사·빌드를 수행하고 기존8090 자원을 보존한다.

## 실제 인수

사용자가 지정한 실제 iPhone Google Chrome에서 카메라·마이크→시작→다른 물리 기기 영상·음성→종료를 확인한다. 권한 거절·앱 전환·잠금·회선 단절 후 정리와 복귀 상태도 기록한다. 양쪽 기기, iOS/Chrome 버전, HTTPS, 네트워크와 관측 결과를 남긴다. 모바일 viewport/가짜 장치를 실제 휴대폰 검사로 표기하지 않는다. Safari·Android는 각각 확인한 환경만 지원표에 기록한다.

기존05의 ABR/품질 전환, 실제 외부망·VAAPI, Google 실제 자격과 공개 배포 인수는 별도로 유지한다. 이 하위 티켓을 통해 원래 필수 모바일 범위를 축소하지 않는다.

## 구현 인계
